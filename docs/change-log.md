## 2026-11-27 ／ Claude ／ PR #5（追加分・検索画面のダークモード）
- 変更：
  1. 検索画面の薄くて見えない文字を明るくした（スライダーの「10万円」、「HOME'Sの駅別参考相場…」の注記、「条件の優先度」、入力欄の薄い案内文）。
  2. 「上限なし」ボタンが真っ白で眩しかったため、他のボタンと同じ暗い配色にした。

## 2026-11-27 ／ Claude ／ PR #5（追加分）
- 変更：
  1. 駅ページ冒頭の4ブロック（見出し・読み・一言の特徴・紹介文）に段差を付けた。見出しを小さく太く（スマホ32px）、一言の特徴に左の太線、紹介文を字下げ。
  2. 「1K家賃目安」「車と道路」などの要点と「暮らしのポイント」で、本文に左の細線と字下げを付け、見出しと本文を分けた。
  3. 「暮らしのポイント」の番号と見出しを1行に（「01　交通」）。
  4. 見出し・写真キャプション・根拠欄の要約の文末の「。」と、写真番号の「01.」の「.」を外した。
  5. 「条件に合う理由・出典」を、小さな三角だけでなく見出し行のどこを押しても開閉できるようにした。
  6. CSS・JSの版数の置き換えを、決まった古い番号だけでなく任意の番号に効くようにした（`scripts/build.mjs`）。
- 理由：実際に読んだ人から、冒頭が左端に真っ平に揃っていて目が滑る、見出しと本文の区別がつきにくい、番号と見出しが別の行で違和感がある、見出しの「。」が不要、開閉の当たり判定が小さい、との指摘があった。6は、古い番号を固定で置き換えていたため、版数を上げるたびに一部のページだけ古い番号が残ったため。
- 影響範囲：全駅ページ（冒頭・要点・暮らしのポイント・根拠欄・見出し・写真キャプション）。
- 未確認・今後：実機のスマホとダークモードでの見え方。キーボード操作での開閉は従来どおり三角のボタンで行う。

## 2026-11-27 ／ Claude ／ PR未作成（ブランチ `readability/station-text-flow`）
- 変更：
  1. 日本語の改行位置を文節単位にした（`word-break: auto-phrase`、`line-break: strict`、`text-wrap: pretty`）。対応していないブラウザでは従来どおり折り返す。

- 理由：
  1. 「つく／ばエクスプレス」「京急バ／ス」「街で／す。」のように、単語の途中や1〜2文字だけで改行されていた。

  3. 見出しと本文が同じ左端で並び、「／」や「・」でつないだ名詞の羅列が文章のように表示されて、情報が分離して見えなかった。
- 影響範囲：全駅ページ・テーマページの本文の折り返し（1）、駅ページの「暮らしのポイント」（2）、駅ページの「条件に合う理由・出典」（3）。
- 補足：`npm run build` の実行により、コミット済みの公開用HTML（`public/`）のタイトル・説明文・見出し・パンくずなども、最新のビルド結果に揃った。本番はデプロイ時にビルドされており、これらはすでに本番に出ている内容で、本番の見た目への新しい変更ではない。
